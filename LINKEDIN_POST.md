# LinkedIn post

LinkedIn truncates at roughly **210 characters** on desktop and **140 on mobile**
before "…see more". Everything that has to earn the click lives above that line.
Each option below puts the hook in the first two lines and the payoff before the
fold.

Pick one, paste, attach the video.

> already breached SLA — because two employees share a display name and it
> wouldn't guess which person it was.

**Why it works:** line one names the thing everyone else is proud of; line two
takes it away. That tension is the whole click.

## Before you post

- **Attach the video directly.** Native uploads outreach link posts substantially;
  don't put a YouTube link in the body.
- **Tag @Supervity and @Vijay Navaluri** using LinkedIn's `@` picker so they
  resolve to real profiles — typed text doesn't notify anyone.
- **Hashtags at the very end**, after the sign-off.
- **Consider leaving the live URL out of the post itself.** `AUTH_BYPASS=true`
  means anyone with the link can edit policies. Put it in the submission form,
  and add it as a comment afterwards only if you want it public.
- **Reply to your own post within the first hour** — one comment adding a detail
  (the four-language incident, say) meaningfully extends reach.
